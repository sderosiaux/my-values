# My values

Six values, told as a run across the rooftops: **[sderosiaux.github.io/my-values](https://sderosiaux.github.io/my-values/)**

| Value | In one line |
|---|---|
| END TO END | I take ideas all the way to prod. |
| SPEED | Fast if I can undo it. Careful if not. |
| SHOW IT | I'd rather demo than pitch. |
| LIMITS | Push the tools. Admit my limits. |
| JUDGMENT | AI does the work. I make the call. |
| SHARE | I share everything I learn. |

They're how I work, and what I look for in the people I work with at [Conduktor](https://conduktor.io). The full text of each one is in the run.

## Under the hood

three.js through React Three Fiber, a scripted first-person camera over a procedural city. The score comes from Google's Lyria and the sound effects from ElevenLabs, both generated by `npm run gen:audio` (needs `GEMINI_API_KEY` and `ELEVENLABS_API_KEY`; existing files are kept).

```bash
npm install
npm run dev
```

`?debug` exposes `window.__mv` to drive the run from a test browser.
